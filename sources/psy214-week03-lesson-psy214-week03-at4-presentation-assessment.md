## PSY114 PSY214 Stress, Self-Care and Mindfulness - Information Sheet Practical Guide

This lesson provides practical guidance for completing the information sheet assignment in PSY114 and PSY214 courses. It covers how to access necessary software tools like Microsoft Word, PowerPoint, and OneDrive, as well as detailed instructions on preparing both a client version (visual A4 double-sided) and a practice manager version (text-based document). The lesson emphasizes the importance of proper citation and referencing in academic work, discusses image sources and attribution rules, and offers step-by-step guidance for saving assignments as PDF files for submission. It also includes information on accessing assignment dropboxes on MyLO and verifying submissions.
