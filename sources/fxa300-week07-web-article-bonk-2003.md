## Guilford’s Alternative Uses Task (1967)

The document provides an overview of Guilford’s Alternative Uses Task (1967), a creativity assessment tool where participants list various uses for a common household item. Scoring includes four components: Originality, Fluency, Flexibility, and Elaboration. The task can be administered in a classroom or individually and does not require specific training. It is one of several similar tests mentioned, including Wallas and Kogan (1965) and the Torrance Tests of Creative Thinking (1974).
