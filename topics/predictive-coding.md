## Predictive Coding in Cognitive Neuroscience

Predictive coding (PC) is a theoretical framework within cognitive neuroscience that posits the brain actively predicts sensory inputs and corrects these predictions based on feedback from the environment. This model is applied across various sensory modalities and cognitive processes, including music perception, visual processing, and language understanding. In the auditory domain, the Predictive Coding of Music (PCM) model proposes an active role for auditory networks in making and updating predictions about incoming musical sounds. Visual processing incorporates predictive coding through feedback loops and cortical magnification, enhancing the predictive nature of perception. Predictive coding also influences the procedural memory and dual-stream framework in the context of artistic expression affected by Alzheimer's disease, suggesting that procedural memory retains some predictive capabilities even as declarative memory declines. Lastly, the Wernicke-Lichtheim model of language processing integrates predictive coding, highlighting its role in syntactic processing and grammar acquisition. Across these studies, predictive coding is consistently highlighted as a central concept in understanding how the brain processes and predicts sensory information, underscoring its importance in cognitive neuroscience.

## Key Findings

- Predictive coding is a fundamental concept in cognitive neuroscience, influencing multiple sensory modalities and cognitive processes.
- Feedback loops and cortical magnification enhance predictive coding's role in visual and auditory processing.
- Procedural memory retains predictive coding capabilities even as declarative memory declines in Alzheimer's disease.

## Open Questions

- How does predictive coding integrate with other cognitive theories and models, such as the Wernicke-Lichtheim model, in explaining complex cognitive functions like language and music perception?
